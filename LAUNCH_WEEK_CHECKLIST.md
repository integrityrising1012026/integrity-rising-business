- [ ] Choose workbook pricing: $7–$17 per book

- [ ] Choose 3-5 brand colors
- [ ] Create/download logo
- [ ] Design workbook cover template (use Canva)
- [ ] Create social media graphics (minimal for now)
- [ ] Write 2-3 core brand messages

**Accounts & Tools**
- [ ] Confirm WordPress access (integrityrising.wordpress.com)
